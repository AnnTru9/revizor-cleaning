# Сайт клининговой службы «Ревизор» — исправленная версия

Папка `docs` содержит готовую версию сайта для GitHub Pages. Стили находятся в обычной папке `assets`, поэтому GitHub не сможет скрыть их при публикации.

Важно: создайте репозиторий с точным названием `revizor-cleaning`, потому что сайт собран для адреса:

`https://ВАШ-ЛОГИН.github.io/revizor-cleaning/`

## Как опубликовать

1. Создайте на GitHub новый публичный репозиторий `revizor-cleaning`.
2. Если в репозитории уже есть старая папка `docs`, удалите её.
3. Нажмите **Add file → Upload files**.
4. Перетащите в окно GitHub новую папку `docs` целиком и файл `README.md`.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В блоке **Build and deployment** выберите:
   - **Source:** Deploy from a branch;
   - **Branch:** main;
   - **Folder:** /docs.
8. Нажмите **Save**.
9. Через 1–3 минуты обновите страницу Settings → Pages. Там появится адрес сайта.

Кнопки телефона, Telegram и форма заявки уже настроены.
