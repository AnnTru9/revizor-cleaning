# Сайт клининговой службы «Ревизор»

Папка `docs` содержит готовую версию сайта для GitHub Pages.

Важно: создайте репозиторий с точным названием `revizor-cleaning`, потому что сайт собран для адреса:

`https://ВАШ-ЛОГИН.github.io/revizor-cleaning/`

## Как опубликовать

1. Создайте на GitHub новый публичный репозиторий `revizor-cleaning`.
2. Откройте репозиторий и нажмите **uploading an existing file**.
3. Перетащите в окно GitHub папку `docs` целиком и файл `README.md`.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В блоке **Build and deployment** выберите:
   - **Source:** Deploy from a branch;
   - **Branch:** main;
   - **Folder:** /docs.
7. Нажмите **Save**.
8. Через 1–3 минуты обновите страницу Settings → Pages. Там появится адрес сайта.

Кнопки телефона, Telegram и форма заявки уже настроены.
